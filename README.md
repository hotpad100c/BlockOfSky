# Sky

A block that shows the sky (`sky:sky`). It is unbreakable and blast-proof, and has no recipe; it is in the creative Building Blocks tab. A redstone signal turns it off.

* Without a shader pack it shows the vanilla sky and clouds.
* With an Iris shader pack it shows the pack's own sky.

Minecraft 1.21.1, NeoForge. Iris 1.8 is optional.
